# LineFour

Four-bar contrary-motion desk for the bars in front of a finished hook.

FluidR3 violin descends while the upright bass climbs through I–vi–IV–V. Piano comps. Woodblock marks the bar. Same-way mode keeps both chairs on roots so you can hear why the loop never leans into HookGrid.

Not ThirdFour (static thirds). Not WalkFour (walking chorus bass). Not EarnFour (groove wait). Not ShakeFour (percussion lift). Not MixForge, AuraMix, or Sideman.

Audio stays in the tab. Samples load from FluidR3 GM on jsDelivr. Flat note names only; missing sharps are pitched from the nearest live sample.
